# Learn English with Friends

跟着《老友记》学英语，把听到的日常表达，变成自己说得出口的英语。

这里用 Markdown 记录逐集学习笔记，包括词汇、地道表达、听力难点、跟读练习和原创造句。从第一季开始，边看、边学、边复习。

## 学习目标

- **听得懂**：熟悉日常对话中的语速、连读、弱读和语气。
- **理解准确**：结合人物关系和情境理解表达，留意玩笑、反讽与文化背景。
- **说得出来**：通过跟读、复述和造句，把输入转化成自己的表达。
- **记得长久**：定期回顾高频表达，记录容易混淆和反复听错的地方。

不追求一次记住所有生词，优先积累能在生活中用到的表达。

## 笔记内容

| 模块 | 记录内容 |
| --- | --- |
| 词汇与短语 | 含义、搭配、语体和适用场景 |
| 地道表达 | 表达意图、语气，以及自然的中文解释 |

## 怎么学一集

1. **理解情节**：先看一遍，理解人物关系和场景，不急着查每个单词。
2. **分段精听**：每次选一小段，先听，再对照英文字幕检查遗漏。
3. **挑选表达**：记录少量值得学的表达，写清楚意思、语气和使用条件。
4. **主动输出**：用新表达写几句原创例句，或用英语复述这一段剧情。
5. **间隔复习**：可在次日、一周后和一个月后回顾，并根据遗忘情况调整。

> 听懂一句对白只是起点。能判断什么时候使用，并换成自己的内容说出来，才是这份笔记想达到的目标。

每集一份笔记，使用 `s01e01.md` 这样的文件名，方便排序与查找。后续各季可以继续建立 `season-02/` 等目录。

## 单集笔记模板

新建一集的 Markdown 文件时，可以复制下面的模板：

```markdown
# S01E01 学习笔记

## 1. 知识点总结

| 词汇／表达 | 情境中的含义 | 我的原创例句 |
| --- | --- | --- | 
| | | | 

## 2. 分段文本学习

用自己的话简述情节，再尝试写一段英文复述。

标注该段对话中的知识点。

## 3. 主动输出

用本集学到的表达写三句与自己生活有关的话，或写一段原创对话。

```

## 学习约定

- 笔记以自己的理解、解释、练习和总结为主。
- 区分剧中引用与原创例句；原创例句不标注为角色台词。
- 查词时关注上下文，不把一个中文释义套用到所有场景。
- 留意口语、俚语、讽刺和冒犯性表达，不直接照搬到正式交流中。

## 交流与纠错

欢迎通过 Issue 指出拼写、释义、语法或用法问题，也欢迎通过 Pull Request 补充原创学习心得。提出纠正时，尽量附上具体语境或可靠参考来源。
